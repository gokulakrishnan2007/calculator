# Calculator

A simple and user-friendly calculator built using **HTML, CSS, and JavaScript**.

## About the Project

This project is a basic calculator that can perform common mathematical operations such as addition, subtraction, multiplication, and division.

The main purpose of this project is to practice **HTML structure, CSS styling, and JavaScript functionality**.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Clear button
* Simple and clean design
* Easy-to-use calculator interface

## Technologies Used

* HTML
* CSS
* JavaScript

## Project Files

```text
calculator/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start using the calculator.
